# Golden Property Soulution

Статический адаптивный сайт-визитка по недвижимости в Дубае.

## Запуск

Нужен **Node.js 20+**. Устанавливать зависимости не требуется.

```bash
npm run build  # собирает публикационные файлы в dist/
npm run dev    # локальный сервер http://127.0.0.1:3000 + автоматическая пересборка
npm run check  # проверка HTML-структуры и локальных ресурсов dist/
```

Для размещения на хостинге загрузите содержимое папки `dist/`. Исходники находятся в `src/`: секции HTML — `src/html/`, стили — `src/css/`, логика форм — `src/js/app.js`.

## Важно перед публикацией

1. **Настроить отправку заявок.** В исходном проекте формы не имели `action` или серверного API. Сейчас они проверяют обязательные поля и честно уведомляют, что заявка не отправлена. Подключите реальный сервис/API, обработку ошибок, защиту от спама и политику обработки персональных данных. Нельзя считать, что заявки поступают в CRM.
2. **Указать действительный телефон.** В источнике указан номер `+000 000 000 000`, а ссылка вела на `tel:800`. Во избежание звонка не по тому номеру телефон оставлен текстом. После получения реального номера настройте ссылку `tel:`.
3. **Доработать SEO для публичного домена:** canonical, абсолютный URL изображения Open Graph и, если есть подтверждённые данные компании, schema.org. Без известного домена и реквизитов эти данные не добавлялись.
4. **Проверить юридические и коммерческие утверждения** (ROI, доходность, визы, кредитование). Тексты сохранены из исходного макета и не подтверждены внешними источниками.

## Что изменилось

- Сохранены исходные разделы, изображения, цвета, коммерческие тексты и назначение CTA. Секционные CTA теперь ведут к консультации.
- Исправлены семантика (один `h1`, логичная иерархия заголовков), доступные подписи полей, фокус, skip-link и `prefers-reduced-motion`.
- Переработаны адаптивные сетки, ограничение ширины, размеры полей и кнопок, перенос длинных строк. Ключевые ширины проверены в Chromium.
- Добавлены WebP с JPEG-fallback, `loading="lazy"` и явные размеры изображений; уменьшено количество загружаемого JavaScript.
- Удалена сборка Gulp со множеством неиспользуемых пакетов и Swiper; вместо неё минимальная сборка на Node.js без npm-зависимостей.

## Проверки

- `npm run build`, `npm run check` и `node --check` — успешно.
- Проверено обслуживание HTML и CSS локальным HTTP-сервером — HTTP 200.
- На движке Chromium через Playwright проверены ширины `320, 360, 375, 390, 430, 480, 520, 590, 650, 768, 960, 1024, 1280, 1440, 1920, 2560` px: ошибок JS и горизонтального переполнения нет, все изображения загружаются, `h1` один.
- Проверены переходы на якорь контактов и честный ответ формы при отсутствии обработчика.

**Ограничения тестирования:** в доступной среде браузер блокирует URL-навигацию, поэтому визуальные проверки выполнялись в Chromium/Playwright через загрузку итоговых HTML, CSS, JavaScript и изображений непосредственно в DOM, а не через публичный URL. Lighthouse, реальные Core Web Vitals, Firefox, Safari/iOS, Android и полный аудит WCAG 2.2 AA не выполнялись. Тестировать эти варианты нужно после размещения сайта.
